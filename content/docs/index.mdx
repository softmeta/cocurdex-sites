Cocurdex is a **desktop-first multi-agent development workspace**. Chat, integrated terminal, editor, and browser preview share one shell, so you can run several AI coding agents without losing track of which session needs you.

## Mental model

1. **Workspace, not chat window** — sessions, chat, terminal, editor, and browser preview are peers. The transcript is one pane among several.
2. **Parallel sessions** — run more than one agent without merging them into a single conversation history.
3. **Honest state** — status stays specific: thinking, using tools, waiting for you, unread result.
4. **Agents coordinate agents, under your control** — teams and script runs are durable, daemon-owned, and gated by your approval.
5. **Local-first product data** — notes and issues live in app-owned storage on your machine. The CLI is the supported external boundary; the SQLite file is not a public API.

## What you get

| Surface | Role |
| --- | --- |
| **Desktop app** | Primary place to run agents, edit files, preview UI, and manage notes and issues |
| **Daemon** | Local process that owns the database, sessions, teams, and script runs |
| **CLI (`cocurdex`)** | Open folders; manage notes, issues, search, skills, and worktrees; drive sessions and teams |
| **Product skills** | Optional agent skills (`cocurdex-*`) for PRD → issue → ship work against app-owned data |
