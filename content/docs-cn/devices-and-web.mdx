title: 设备与本地网页
description: 在本机浏览器中打开 Cocurdex，把另一台设备按权限配对，或在同一 daemon 上使用 iOS 与 Android 应用。

桌面应用是主机。**设置 → 设备** 让你从浏览器使用这台主机——本机，或你配对的另一台设备——也可以从 iOS 与 Android 应用使用。

这里不会替换 daemon。浏览器和手机应用连的都是已经在这台机器上运行的 Cocurdex 实例，不会另开一个工作区，也不需要云账号。

## 在浏览器中打开（本机）

**设置 → 设备 → 在浏览器中打开** 会加载本地网页客户端，连到与桌面应用相同的工作区和会话。

CLI 会打印该 URL：

```bash
cocurdex web
```

桌面应用必须在运行，daemon 才能提供该客户端。URL 带有本机 token，请把它当作对本机的访问权限来对待。

## 远程访问

默认关闭。**允许远程设备** 让局域网或 Tailscale tailnet 上已配对的设备连到这台电脑。

- 有可达地址时，界面会列出 **局域网** 和 **Tailscale**。
- 可以设置监听**端口**（字段里会显示默认值）。
- 连接**未加密**。请在受信任的网络上使用，或走 Tailscale。

从 CLI：

```bash
cocurdex host status
cocurdex host remote enable [--port <port>]
cocurdex host remote disable
```

## 配对设备

**配对设备** 会生成一次性配对码。在另一台设备的浏览器里打开配对链接，或在**配对此浏览器**界面输入配对码。在 iOS 或 Android 应用里，把该链接粘贴到**配对电脑**（字段是**配对链接**，然后点**配对**）。应用会加入这台电脑、选中它，然后回到**会话**。

| 设置 | 含义 |
| --- | --- |
| **设备名称** | 显示在已配对设备列表中的标签 |
| **配对码有效期** | 10、30 或 60 分钟 |
| **权限** | 新设备可以做什么（见下） |

若要让对方打开链接，请先开启远程访问。配对码只能用一次。未完成的配对会出现在**待完成的配对**中，直到过期或你**取消**。

```bash
cocurdex host pair --label "My phone" [--scopes read,interact,approvals] [--ttl <minutes>]
cocurdex host pairings
cocurdex host pairing cancel <pairing-id>
```

CLI 默认权限是 `read`、`interact` 和 `approvals`。

## 已配对设备可以做什么

配对时选择权限。**主机管理**（改应用设置、管理设备）只属于这台电脑，不能授给已配对设备。

| 权限 | 允许该设备 |
| --- | --- |
| **读取** | 查看会话、消息、笔记、issue 和演示文稿 |
| **交互** | 发送消息、停止会话、编辑笔记、issue 和演示文稿 |
| **审批** | 处理权限请求、问题和计划审批 |
| **启动任务** | 启动会话、团队和脚本运行 |
| **读取文件** | 读取工作区文件、差异和 Git 状态，并读出工作区里 PowerPoint 文件的提纲 |
| **写入文件** | 编辑工作区文件、暂存、提交，以及把导出的演示文稿写进工作区 |
| **破坏性 Git 操作** | 丢弃更改、切换分支和推送 |
| **凭据** | 管理模型提供方登录、API Key 和 MCP 服务器 |

随时可在**已配对设备**中**吊销**。设备会立即断开，必须重新配对才能再连。

```bash
cocurdex host devices
cocurdex host revoke <device-id>
cocurdex host audit [--limit <n>]
```

**访问记录**记录本机上的配对、吊销和远程访问变更。

## 原生应用

iOS 与 Android 应用有四个标签：**会话**、**Issues**、**笔记**和**电脑**。**电脑**列出已配对的电脑。**会话**、**Issues** 和**笔记**都对应当前工具栏里的那台电脑。

还没有配对电脑时，这些标签会显示**还没有电脑**和**配对电脑**。配对之后，点工具栏上的电脑名称可以切换，或选择**配对电脑**再加一台。

手机上的 **Issues** 和**笔记**是只读的。见[笔记与 Issue](/zh-cn/docs/notes-and-issues/#在手机上)。

会话按工作区分组。**搜索会话**用来筛选。子会话的状态会汇总到根会话那一行：

| 状态 | 含义 |
| --- | --- |
| **需要处理** | 有权限请求、提问或计划在等你 |
| **运行中** | 会话仍在工作 |
| **未读** | 已有结果，你还没打开 |

标题下面的一行更具体，例如**等你批准**、**有问题要问你**、**计划已写好，等你决定**、**正在运行…**、**正在连接…**、**正在后台运行**或**已完成**。运行失败时显示**运行失败**。

手机暂时连不上电脑、但本地已有列表时，列表会保留，并显示**连不上**电脑名称**，显示的是最后一次更新。** 还没有任何列表时，画面是**连不上**该电脑，下面写着**请确认电脑没有休眠，并且和手机在同一网络。**，并提供**重试**。这台电脑没有会话时显示**没有会话**——**在**该电脑**上开始的会话会显示在这里。** 搜索没有命中时显示**没有匹配“…”的会话**。

### 开始一个会话

这台电脑配对时带有**启动任务**（`execute`）时，**会话**工具栏会显示**新建会话**。它打开标题为**新会话**的表单。

提示词的占位是**要让 Agent 做什么？**。提示词为空时，**开始**保持不可用。会话正在打开时，按钮变成**正在开始…**。**运行位置**下面有两行：

| 行 | 打开 |
| --- | --- |
| **工作区** | 这台电脑上的工作区 |
| **Agent** | **Agent**、**模型**和**模式** |

两个选择器都在这张表单里再打开一层。**Agent** 那一行会显示**开始**将要使用的模型和权限模式。行下面写着**在**这台电脑**上运行。**

**工作区**把最近有过会话的工作区排在前面，并先选中它，直到你另选。**搜索工作区**用来筛选。每一行带有会话数量，例如 **3 个会话**。页脚是**新工作区只能在电脑上添加。**

在 **Agent** 里，可以点选的一行写着**可用**。其余写着**电脑上未安装**、**电脑不支持**或**在电脑上启动失败**。**模型**列出这台电脑上服务商提供的模型（**模型来自电脑上配置的服务商。**）。这个 Agent 没有可用模型时，这一节写着**这个 Agent 没有可用的服务商模型，会使用它自带的默认模型。** **模式**列出该 Agent 的权限模式。没有可选模式的 Agent（例如 Pi）会写**这个 Agent 没有可选的权限模式。** 模式 id 见 [Agent](/zh-cn/docs/agents/#权限模式)。

**开始**会按屏幕上的工作区、Agent、模型和模式创建会话，送出提示词，用和桌面应用相同的方式根据提示词命名会话，然后打开它。会话已经创建、但这次**开始**没有完成时，表单会显示**会话没能开始。请检查连接后重试。** 在这张表单上再次点**开始**，会把提示词送进已经创建的那个会话。

打开一行后，底部标签栏隐藏，返回按钮为**会话**。标题是会话名，下面是工作区和模型。记录会随着 Agent 运行而更新：你的消息、助手的消息，以及工具调用。

助手的消息按 Markdown 显示。表格会渲染。代码块会显示语言名、复制按钮和语法高亮。数学公式已关闭。

输入框的占位符是**回复 agent**。**发送**送出消息。会话正在运行且输入为空时，这个按钮是**停止**。发送和停止都需要配对时授予的**交互**权限。

Agent 在等你时，底部的停靠栏会换掉输入框：

- 权限请求，以及给出的选项。
- 提问。在**你的回答**里输入后点**回复**，或直接选一个选项。Agent 没有自定标题时，标题是 **agent 有个问题**。
- 计划，标题是**审阅计划**。**批准**接受计划。**继续规划**让 Agent 继续规划。

配对时没有**审批**权限时，这个停靠栏会显示**请在电脑上批准**和**这台手机配对时没有授予审批权限。** 请在电脑上完成批准。
