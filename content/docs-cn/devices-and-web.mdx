这台电脑上的 daemon 是主机。桌面应用会启动它，没有桌面应用的 [headless 安装](/zh-cn/docs/getting-started/#headless-安装)也会启动它。**设置 → 设备** 让你从浏览器使用这台主机——本机，或你配对的另一台设备——也可以从 iOS 与 Android 应用使用。同一页上的**其他电脑**是另一个方向：这台电脑可以打开并派活的电脑。

这里不会替换 daemon。浏览器和手机应用连的都是已经在这台机器上运行的 Cocurdex 实例，不会另开一个工作区，也不需要云账号。

打开桌面应用会启动这个 daemon。随安装包提供的 CLI，以及 headless 安装里的 CLI，会在没有进程监听时启动它。**设置 → 常规 → Daemon** 里的**后台常驻**让桌面应用的 daemon 在你退出后继续运行，并在登录时启动，因此桌面窗口关掉后，浏览器和已配对设备仍然可用。Headless 安装用 `cocurdex daemon background on` 做同一件事。见 [Daemon](/zh-cn/docs/providers-and-settings/#daemon)和 [Headless 安装](/zh-cn/docs/cli/#headless-安装)。

## 在浏览器中打开（本机）

**设置 → 设备 → 在浏览器中打开** 会加载本地网页客户端，连到与桌面应用相同的工作区和会话。

CLI 会打印该 URL：

```bash
cocurdex web
```

daemon 必须在运行，才能提供该客户端。Headless 安装提供的是同一个客户端。URL 带有本机 token，请把它当作对本机的访问权限来对待。

## 远程访问

默认关闭。**允许远程设备** 让局域网或 Tailscale tailnet 上已配对的设备连到这台电脑。只有已配对的设备能连接，且只拥有你授予的权限。

- 有可达地址时，界面会列出 **局域网** 和 **Tailscale**。
- 可以设置监听**端口**（字段里会显示默认值）。
- **保持电脑唤醒** 会在远程访问开启期间阻止电脑空闲睡眠，让你离开座位时手机也能连上。只要 daemon 在运行，它就一直生效，包括开启**后台常驻**后退出桌面应用。合上笔记本盖子仍会睡眠。

已配对设备与这台电脑之间的流量是端到端加密的。要在其他网络下连到这台电脑，请在两台设备上都装 Tailscale，或使用[中继](#中继)。

从 CLI：

```bash
cocurdex host status
cocurdex host remote enable [--port <port>] [--keep-awake on|off]
cocurdex host remote disable
```

### 中继

**中继** 通过 `cocurdex-relay` 服务让你在任何地方连接这台电脑。中继只转发端到端加密的流量，无法读取内容。只在远程访问开启时生效。

| 设置 | 含义 |
| --- | --- |
| **中继地址** | 官方 Cocurdex 中继（**使用官方**），或自托管的 `cocurdex-relay` 地址。留空即关闭中继 |
| **邀请凭证** | 中继运营方提供的凭证，粘贴后会自动填好中继地址。官方中继只接受受邀请的电脑；无需邀请的自托管中继不用填写 |
| **仅中继** | 只接受通过中继的连接，不再监听本地网络端口 |

**状态** 显示 **在线**（知道往返时间时写作 **在线 · N ms**）、**连接中**、**离线**、**关闭**，或 **开启远程访问后连接**。不开 **仅中继** 时，局域网和 Tailscale 监听保持开启；已配对设备优先使用能连通的直连地址，连不上时回退到中继。

```bash
cocurdex host relay set [official|<url>] [--relay-only on|off] [--credential <file>]
cocurdex host relay off
cocurdex host traffic [--reset]
```

`host traffic` 打印这台电脑自计数开始以来收发了多少远程流量。`--reset` 把计数清零。

### 手机通知

推送网关（`cocurdex-push` 服务）让这台电脑在 Agent 请求审批、提出问题、给出待审计划，以及一轮对话完成或失败时通知已配对的手机。允许通知的手机会自行注册。每条通知都用手机的密钥加密，网关、Apple 和 Google 只能看到密文。

```bash
cocurdex host push set <url>
cocurdex host push status
cocurdex host push off
```

## 配对设备

**配对设备 → 生成配对码** 会生成一次性配对码、二维码和配对链接。链接按可达性排序：中继在线时排最前，其次是 Tailscale，最后是局域网。Headless 安装没有设置界面。`cocurdex host pair` 生成同样的配对码，`cocurdex host approve` 用来输入安全码。

- **iOS 或 Android 应用：** 选择**配对电脑**，然后点**扫码配对**扫描二维码，或点**粘贴配对链接**再点**配对**。应用会加入这台电脑、选中它，并打开**在电脑上批准**。这一屏显示要在电脑上输入的六位**安全码**。电脑允许这台手机并且连接已经建立后，状态是**已配对**，画面随后关闭。然后回到**助理**。已配对的手机会记住电脑上报的所有地址，自动切换到能连通的那个。
- **另一台设备上的浏览器：** 打开配对链接，或在**配对**界面粘贴链接。其他设备上的浏览器只能通过[中继](#中继)连接，请先开启中继。

电脑的所有地址都连不上时（比如不在同一 Wi-Fi，或接入点隔离），**配对**和扫码界面会显示**无法连接到电脑。请确认它已联网，且手机能通过本地网络或中继访问它。**

| 设置 | 含义 |
| --- | --- |
| **设备名称** | 显示在已配对设备列表中的标签 |
| **配对码有效期** | 10、30 或 60 分钟 |
| **权限** | 新设备可以做什么（见下） |

若要让对方打开链接，请先开启远程访问。配对码只能用一次。未完成的配对会出现在**待完成的配对**中，直到过期或你**取消**。

用掉配对码还不会连上。设备会停在等待批准，并显示六位**安全码**。电脑上弹出**允许 &#123;名称&#125; 使用这台电脑？**，需要你输入这个安全码。**允许**后才会连上。**拒绝**会吊销它。关掉对话框后请求仍在等待；**已配对设备**里能看到它在等待，但不显示安全码，所以必须从设备上读。安全码连续错五次会吊销该设备。请求在 10 分钟后失效。

正在等待的浏览器显示**等待批准**和同一个安全码，电脑允许后才会打开工作区。手机上，扫码或粘贴配对链接后，**在电脑上批准**会立刻显示**安全码**。电脑列表里这台电脑显示**等待电脑批准**，直到批准完成，手机会持续检查，所以点**允许**后**会话**很快就会出现。**安全码**下面有一条实时状态。等待时，**等待电脑批准**旁边有一个转圈。手机没有网络连接时，状态是**无法连接**。电脑允许这台设备并且连接已经建立后，状态是**已配对**。画面随后关闭，手机连上。请求过期或被撤销时，状态是**配对已过期或已被撤销。请在电脑上重新发起配对。** 已吊销的手机在电脑列表里显示**访问已撤销**。可以在对话框、**已配对设备**或下面的 `cocurdex host approve` 里批准。

带有**管理设备**权限的已配对设备可以批准或吊销其他设备。**主机管理**（修改应用设置）只属于这台电脑，不能授出。

```bash
cocurdex host pair --label "My phone" [--scopes read,interact,approvals] [--ttl <minutes>]
cocurdex host pairings
cocurdex host pairing cancel <pairing-id>
```

CLI 默认权限是 `read`、`interact` 和 `approvals`。

## 已配对设备可以做什么

配对时选择权限。

| 权限 | 允许该设备 |
| --- | --- |
| **读取** | 查看会话、消息、笔记、事项和演示文稿 |
| **交互** | 发送消息、停止会话、编辑笔记、事项和演示文稿 |
| **审批** | 处理权限请求、问题和计划审批 |
| **启动任务** | 启动会话、团队和脚本运行；修改或运行 MCP 服务器；给不经询问就执行工具的会话发消息，以及把它切到这种模式 |
| **读取文件** | 读取工作区文件、差异和 Git 状态，并读出工作区里 PowerPoint 文件的提纲 |
| **写入文件** | 编辑工作区文件、暂存、提交，以及把导出的演示文稿写进工作区 |
| **破坏性 Git 操作** | 丢弃更改、切换分支和推送 |
| **凭据** | 管理模型提供方登录和 API Key，并查看 MCP 服务器 |
| **管理设备** | 查看、批准和吊销已配对的设备 |

已配对设备要驱动「不询问就执行」的 Agent，需要**启动任务**。这包括能跑工具的 Pi 会话（Pi 的 Chat 不算），以及会自动批准每次工具调用的权限模式。把模式改离开普通模式或计划模式，也需要同一权限。改模型或推理强度不需要。这时手机上的输入框会换成：**这个 agent 执行命令不需要批准，给它发消息需要此设备拥有「启动任务」权限，请在电脑上授予。** 已配对的浏览器会在会话里显示被拒绝。

**已配对设备** 列出每台设备的权限、最近在线时间和六位**安全码**。手机上这台电脑的详情页会显示相同的**安全码**。安全码一致，说明双方密钥没有被替换；不一致时请吊销该设备并重新配对。标为**在启用加密前配对**的设备需要吊销后重新配对。

**修改权限** 会修改在线设备的权限并让它重新连接。随时可在**已配对设备**中**吊销**。设备会立即断开，必须重新配对才能再连。

```bash
cocurdex host devices
cocurdex host approve <device-id> --code <safety code>
cocurdex host revoke <device-id>
cocurdex host scopes <device-id> --scopes <list>
cocurdex host audit [--limit <n>]
```

**访问记录**记录本机上的配对、吊销、中继和远程访问变更。

## 其他电脑

**设置 → 设备 → 其他电脑**列出这台电脑可以打开并派活的电脑。这一组的说明是**这台电脑可以打开并派活的其他电脑。用另一台电脑生成的配对链接来配对。** 还没有时，写着**还没有配对其他电脑。**

配对只走一个方向。在另一台电脑上，这台电脑出现在**已配对设备**里，和普通已配对设备一样。那台电脑上的**其他电脑**一行，要在那边另行配对才会出现。

在另一台电脑上打开**设置 → 设备**，创建一条允许**启动任务**（`execute`）的配对，同时带上**读取**和**交互**。复制它的配对链接。在那台电脑的 CLI 上：

```bash
cocurdex host pair --label "<this computer>" --scopes read,interact,execute
```

还要别的权限时，写在同一份 `--scopes` 里。这台电脑要把工作交过去，需要 `execute`。默认权限 `read,interact,approvals` 不含它。要让另一台电脑给出这台电脑能打开的链接，请先在那边开启远程访问。见[配对设备](#配对设备)。

在这台电脑上，**配对电脑**打开**配对另一台电脑**。把链接粘贴进**配对链接**（占位是**粘贴另一台电脑上的配对链接**），然后点**配对**。对话框写着**在另一台电脑上打开 设置 > 设备，配对设备时勾选“启动任务”，然后复制配对链接。** 配对之后，对话框显示安全码，以及**已与 &#123;名称&#125; 配对。请确认两台电脑上的安全码一致。** 点**完成**关闭。

在这台电脑上，CLI 是同一步：

```bash
cocurdex host remotes pair <pairing link> [--label <name for this computer>]
```

`--label` 是另一台电脑上显示的这台电脑的名称。省略时，名称是这台电脑的主机名。命令打印 `Paired with <name> (<host id>)` 和 `Safety code: <code>`。配对还在等待时，还会打印 `On <name>, approve this computer: cocurdex host approve <device-id> --code <code>`。

这一行是**等待批准**时，在另一台电脑上核对安全码一致后再批准。对话框写着**在 &#123;名称&#125; 上打开 设置 > 设备，确认安全码一致后批准这台电脑。** 可以在那个对话框里批准，也可以在另一台电脑的**已配对设备**里批准，或用 `cocurdex host approve <device-id> --code <code>`。

缺少**读取**、**交互**或**启动任务**时，对话框写着**要把工作交给 &#123;名称&#125;，它还需要允许：&#123;权限&#125;。** 这里的权限名是权限标题，例如**读取**、**交互**和**启动任务**。CLI 打印 `To delegate work there, <name> must also grant: <scopes> (cocurdex host scopes <device-id> --scopes ...)`，其中 `<scopes>` 是缺少的权限 id，例如 `read, interact, execute`。

每一行显示状态和安全码，格式是 **&#123;状态&#125; · 安全码 &#123;安全码&#125;**：

| 状态 | 在 `cocurdex host remotes list` 里 |
| --- | --- |
| **检查中** | `unknown` |
| **已连接** | `connected` |
| **等待批准** | `pending` |
| **离线** | `offline` |
| **访问已撤销** | `rejected` |

`list` 的列是 `hostId`、`name`、`status`、`scopes`、`safetyCode` 和 `pairedAt`。还没有配对的电脑时，它打印 `No records`。

**打开**在独立的桌面窗口里打开那台电脑。窗口标题是那台电脑的名称，窗口里跑的是同一个应用，连的是那台电脑的 daemon。**打开**属于桌面应用。本地网页客户端不放这个按钮，已经在显示另一台电脑的窗口里也不放。状态是**访问已撤销**时，**打开**保持隐藏。

**移除**会在另一台机器上吊销这台电脑，并停止跟踪派到那里的工作。确认标题是**移除 &#123;名称&#125;？**，说明是**这台电脑将失去对它的访问，派到那里的工作也不再在这里跟踪。** CLI 打印 `Removed <name>`。

```bash
cocurdex host remotes list [--json]
cocurdex host remotes pair <pairing link> [--label <name for this computer>] [--json]
cocurdex host remotes workspaces <computer> [--json]
cocurdex host remotes remove <computer>
```

`<computer>` 是 host id 或完全一致的名称。多台电脑同名时，传 id。这时 CLI 提示 `Several paired computers are named "<name>"; pass its id`。没有匹配时提示 `No paired computer matches "<name>"`。`workspaces` 打印那台电脑上工作区的 `id` 和 `name`。

把助理的工作交给其中一台电脑，见[另一台电脑](/zh-cn/docs/assistants/#另一台电脑)。iOS 与 Android 应用不列出**其他电脑**，也不会打开这些窗口。

## 原生应用

iOS 与 Android 应用有四个标签：**会话**、**事项**、**笔记**和**设置**。标签栏浮在靠近底部边缘的位置。应用打开时是**助理**。**会话**标签上的标题可以在**助理**、**工作**和**聊天**之间切换，说明分别是**和你的专属助理协作**、**在工作区执行任务**和**直接和模型对话**。**设置**里有**电脑**，列出已配对的电脑。**助理**、**工作**、**聊天**、**事项**和**笔记**都对应当前工具栏里的那台电脑。

在 Android 上，启动画面使用和桌面应用相同的标志，浅色和深色各一份。它会留到第一屏拿到数据为止；如果 3 秒后数据还没到，启动画面也会关掉。

还没有配对电脑时，这些标签会显示**还没有电脑**和**配对电脑**。配对之后，点工具栏上的电脑名称可以切换，或选择**配对电脑**再加一台。

每台电脑显示**已连接**和往返毫秒数、**正在检测**、**无法连接**、**等待电脑批准**或**访问已撤销**。这台手机还在等电脑允许时，这一行保持**等待电脑批准**并持续检查，允许之后很快变成**已连接**。已吊销的手机显示**访问已撤销**。电脑的地址都没有应答时才是**无法连接**。打开一台电脑可以看到**权限与连接**，其中包括**安全码**。**重命名**只改这台手机上的名称。**移除这台电脑**会去掉配对；电脑离线时，之后在电脑的**设置 → 设备**里吊销。

页面出错时，应用仍保持打开，整屏显示**这个页面出错了**，下面是错误信息，并提供**重试**。

### 助理

**助理**按工具栏里的那台电脑列出两节，有内容时才出现：

| 节 | 显示 |
| --- | --- |
| **今天** | 今天成功、且不是静默的例行任务结果 |
| **助理** | 这台电脑上的助理 |

每个助理一行显示最新回复；主线程正在运行时显示**工作中**。还没有回复时，这一行是简介。助理还没回复的汇报不会换掉这一行。行上还有最近一条消息的时间、状态点，以及免打扰时的静音铃铛，读作**免打扰**。免打扰的一行会藏起未读标记。免打扰的助理不会通知手机；需要你处理的事项仍出现在**概览**的**需要你处理**里。

标题栏的**新建助理**打开**新建助理**。这需要**交互**权限。有可用模型时，表单打开时已经填好：一个这台电脑上还没有助理用过的名字，默认助理的模型（这个模型仍然可用时，否则是第一个兼容的模型），以及一个头像。再次打开会重新取一个名字和头像。字段是**名称**、**简介**、**头像**、**模型**、**指令**和**人设**（最多 20,000 个字符）。**头像**里有**形状**、**表情**（**平静**、**开心**、**眨眼**、**困倦**、**好奇**）、**颜色**和**自定义表情**。**模型**显示已经填上的模型。列表里仍有**默认**；选它之后，**创建**会按同样的方式选一个模型。**创建**会打开新的主线程，并请助理问候你。保存失败时显示**保存失败，请重试。** 没有可用模型时，表单不会打开，画面写着**请先在电脑上配置模型，再新建助理**。草稿准备不了时，写着**无法准备新助理**，并提供**重试**。电脑上的 Cocurdex 版本过旧时，标题下面写着**电脑上的 Cocurdex 版本过旧，更新后再试。**

长按一行（需要**交互**）可以**编辑**、**置顶** / **取消置顶**（默认助理没有这项）、**免打扰** / **取消免打扰**、**复制**和**删除**。**编辑**打开**编辑助理**，字段相同，**保存**后回到列表。**复制**会在名称后加上**副本**，并打开副本的线程。**删除**的确认标题是删除「助理名」？，引号里是这个助理的名称，说明是**将删除这个助理和它的对话。记忆仍保留在记忆库中。** 操作失败时显示**操作失败，请重试。**

点一个助理打开它的主线程。主线程还是空的、并且手机有**交互**权限时，助理会在这时写下问候。标题栏的**概览**打开这个助理的一页：

| 节 | 显示 |
| --- | --- |
| **需要你处理** | 这个助理还在等你、或已经失败的事项。没有时不显示这一节。需要你处理或受阻的例行任务标为**需要你处理**，静默的任务也一样 |
| **委派的工作** | 这个助理交给某个工作区、并且仍是**运行中**或**空闲**的工作。标题下面一行是工作区和这个状态。还没有时，页脚是**这个助理委派的工作会显示在这里。** 列表加载失败时，页脚是**工作列表加载失败，下拉刷新后重试。** |
| **最近结果** | 已经结束的委派工作。标题下面一行是工作区，以及**本轮已完成**、**失败**、**已取消**、**已中断**或**已归档**。没有时不显示这一节 |
| **例行任务** | 只读列表。名称下面一行是**下次运行：**加上时间、**已暂停**、**多次失败后已暂停**，或**没有安排下次运行**。有运行线程时，点一行打开最近一次运行。页脚是**例行任务在已连接的电脑上运行，需要它的后台服务在线。** 列表加载失败时，页脚是**例行任务加载失败。** |
| **上下文与资料** | **笔记**和**事项**，点开会打开对应的标签 |

概览标题显示头像、名称和简介。没有简介时写着**协调工作、记住上下文、跟进到底。**

点**需要你处理**里的一行，或一条结果，打开那个会话。还没有助理时，画面是**还没有助理**，以及**助理记住上下文、跟进工作，并向你汇报结果。** 这一屏上有**新建助理**，需要**交互**权限。手机连不上电脑时，会写**无法连接**那台电脑，并提供**重试**。

助理线程不会出现在**工作**里。线程中，贴进来的简报标为**今日简报**，贴进来的例行任务结果标为**来自例行任务**加上任务名称。每一条都单独成一轮。助理还没回答的委派汇报是一行浅色文字，不是气泡：会话标题、结果（**已完成**、**需要你决定**、**受阻**、**失败**、**已取消**或**已中断**），以及**等待助理处理**。助理回答之后，回复上写着**依据**和会话标题。点标题打开那个会话。

配对带有**交互**时，手机上的**事项**和**笔记**可以编辑。见[笔记与 Issue](/zh-cn/docs/notes-and-issues/#在手机上)。

在**工作**里，**显示选项**对应手机放得下的桌面控件：**分组**（工作区、状态、Agent、最近更新或不分组）、**排序**，以及按 Agent、状态和环境（本地或工作树）筛选、**每组会话数**和**已归档会话**。当**分组**不是**不分组**、列表没有在搜索、并且不止一组时，标题下面有一排：**全部**，以及当前分组里的每一组；有置顶的会话时也包括**已置顶**。**全部**不带数量。其余每一枚显示该组的会话数。选中一组后，列表只显示这一组的全部会话，没有分组标题，也不会再提示显示更多。这个选择会保留；**分组**一变，就回到**全部**。正在搜索时，以及列表不分组时，这一排会隐藏。**置顶**把一行留在最上面。一行的菜单可以**重命名**、**分叉会话**、**标为未读**、**归档**或**删除**。**搜索会话**用来筛选。子会话的状态会汇总到根会话那一行：

| 状态 | 含义 |
| --- | --- |
| **需要处理** | 有权限请求、提问或计划在等你 |
| **运行中** | 会话仍在工作 |
| **未读** | 已有结果，你还没打开 |

标题下面的一行显示模型名称；运行状态更相关时则显示状态，例如**等你批准**、**有问题要问你**、**计划已写好，等你决定**、**正在运行…**、**正在连接…**、**正在后台运行**或**已完成**。运行失败时显示**运行失败**。

手机暂时连不上电脑、但本地已有列表时，列表会保留，并显示**连不上**电脑名称**，显示的是最后一次更新。** 还没有任何列表时，画面是**连不上**该电脑，下面写着**请确认电脑没有休眠并已联网，且手机能通过本地网络或中继访问它。**，并提供**重试**。这台电脑没有会话时显示**没有会话**——**在**该电脑**上开始的会话会显示在这里。** 搜索没有命中时显示**没有匹配“…”的会话**。

### 开始一个会话

这台电脑配对时带有**启动任务**（`execute`）时，**工作**的工具栏会显示**新建会话**。它打开标题为**新会话**的表单。

提示词的占位是**要让 Agent 做什么？**。提示词为空时，**开始**保持不可用。会话正在打开时，按钮变成**正在开始…**。**运行位置**下面有两行：

| 行 | 打开 |
| --- | --- |
| **工作区** | 这台电脑上的工作区 |
| **Agent** | **Agent**、**模型**和**模式** |

两个选择器都在这张表单里再打开一层。**角色**列出这台电脑上保存的角色；选中一个会填上它的 Agent、模型和权限。**Agent** 那一行会显示**开始**将要使用的模型和权限模式。这台电脑上没安装的 Agent 不会出现在这份列表里。行下面写着**在**这台电脑**上运行。**

**工作区**把最近有过会话的工作区排在前面，并先选中它，直到你另选。**搜索工作区**用来筛选。每一行带有会话数量，例如 **3 个会话**。页脚是**新工作区只能在电脑上添加。**

在 **Agent** 里，可以点选的一行写着**可用**。其余写着**电脑上未安装**、**电脑不支持**或**在电脑上启动失败**。**模型**列出这台电脑上服务商提供的模型（**模型来自电脑上配置的服务商。**）。这个 Agent 没有可用模型时，这一节写着**这个 Agent 没有可用的服务商模型，会使用它自带的默认模型。** **模式**列出该 Agent 的权限模式。没有可选模式的 Agent（例如 Pi）会写**这个 Agent 没有可选的权限模式。** 模式 id 见 [Agent](/zh-cn/docs/agents/#权限模式)。

**开始**会按屏幕上的工作区、Agent、模型和模式创建会话，送出提示词，用和桌面应用相同的方式根据提示词命名会话，然后打开它。会话已经创建、但这次**开始**没有完成时，表单会显示**会话没能开始。请检查连接后重试。** 在这张表单上再次点**开始**，会把提示词送进已经创建的那个会话。

### 笔记、事项和对话记录

在**笔记**里，标题下面一行是正文的纯文本摘录。在**事项**里，标识符用等宽字体。在事项详情里，**子事项**下的每一行都会打开对应的事项。

打开一个工作会话后，底部标签栏隐藏，返回按钮为**会话**。标题是会话名，下面是工作区和模型。记录会随着 Agent 运行而更新：你的消息、助手的消息，以及工具调用。一轮还在进行时，活动那一行显示**正在工作**、**思考中**或**回复中**。正在进行的工具会写在这一行上。

助理的主线程和聊天线程是一段对话。助理的标题是头像和名称，旁边是**概览**。你的消息是气泡；在助理线程里，气泡带上头像的颜色，回复则保持中性。这段记录里没有工具调用，也不显示**提问目录**。

聊天一轮在回复进入线程之前显示**思考中**；回复已经出现、这一轮还在进行时显示**回复中**。它不会显示**正在工作**。助理一轮与[桌面主线程](/zh-cn/docs/assistants/#主线程)一致：头像和**思考中**，15 秒后变成**还在想，稍等**，40 秒后变成**这次有点慢，再等等**。正在使用工具时，这一行是**正在处理**。回复一开始流出，这一行就消失。

聊天或助理的一条回复结束时，有**复制**，并会短暂显示**已复制**。聊天回复可以显示这一轮用了多久；这一轮被停下时显示**已停止**，并写成**已停止 · 12s**。助理回复可以显示**已停止**，不带这段时长。助理线程里，隔了一个小时，或者换了一天，中间会显示时间。

助理的输入框保持一行，没有模型、推理强度或模式选项。助理线程还是空的、并且没有在运行时，会显示**建议**：**今天有什么需要我关注的？**、**每天早上 8 点给我一份简报**、**你记得关于我的哪些事？** 点一条就会发出去。新助理正在写问候时，这份列表换成头像和一行闪光的**工作中**。占位是**给**助理的名字**发消息**。

已有的聊天里，手机配对时带有**启动任务**时，输入框可以当场切换模型和**推理强度**。**新建聊天**也有同样的控件。**推理强度**只在模型提供不止一个档位时显示。新建聊天会沿用最近一次聊天的档位（这个模型仍然提供时），否则从**中**开始。占位是**给模型发消息**。聊天模型加载不了时，**新建聊天**写着**无法加载聊天模型**，并提供**重试**。电脑上的 Cocurdex 版本过旧时，标题下面写着**电脑上的 Cocurdex 版本过旧，更新后再试。** 电脑上还没有聊天模型时，写着**请先在电脑上配置聊天模型**。

助手的消息按 Markdown 显示。表格会渲染。代码块会显示语言名、复制按钮和语法高亮。语言为 `mermaid` 的代码块会画成图，主题与桌面应用同一套。绘制失败时，或手机离线、无法绘制时，源代码按普通代码块显示。数学公式会渲染，包括行内公式、独立公式和表格中的公式。

点记录里的图片会打开全屏查看。iOS 上可以双指缩放。Android 上同样是全屏查看，暂不支持双指缩放。**关闭**退出查看。

在工作会话里，点工具调用那一行会打开详情。标题栏显示状态——**已完成**、**失败**或**运行中**——调用结束后还会显示耗时（秒）。下面是**输入**和**输出**。很长的输出只显示末尾，并标为**末尾 64 KB**。画面上有输出时，**复制输出**会复制这段文字。输出无法加载时，画面显示**无法加载输出**。排版与桌面应用一致。

在工作会话里，输入框的占位符是**回复 agent**。**添加照片**可以附上不超过 10 MB 的 PNG、JPEG、GIF 或 WebP。**发送**送出消息。会话正在运行且输入为空时，这个按钮是**停止**。发送和停止都需要配对时授予的**交互**权限。

记录里的文件链接，或工具调用点名的文件，会打开预览。Markdown 可以在**显示预览**和**显示源码**之间切换。**显示预览**里的 Markdown 可以选中，并使用系统的选择工具栏；代码块标题上仍有复制按钮。**复制内容**复制文本。过长的文件会写**仅显示此文件的前 512 KB。** 二进制文件写**无法预览此文件。** 工作区以外的路径写**这个文件不在电脑的工作区内。**

**跳到最新消息**和**跳到第一条消息**用来跳过很长的记录。最新消息还在可见区域下面时，才会出现**跳到最新消息**。已经能完整放下的短线程不会显示它。顶栏菜单里的 **Agent 设置**显示模型、推理强度、快速模式，以及这个 Agent 有的协作模式和变体，还有本会话的 MCP 服务器。**另存为角色…**把当前配置存在这台电脑上。在工作会话里，一条回复结束时有**复制**，并会短暂显示**已复制**，还有**从这里分叉**。也可以显示这一轮用了多久；这一轮被停下时显示**已停止**，并写成**已停止 · 12s**。

Agent 在等你时，底部的停靠栏会换掉输入框：

- 权限请求，以及给出的选项。
- 提问。在**你的回答**里输入后点**回复**，或直接选一个选项。Agent 没有自定标题时，标题是 **agent 有个问题**。
- 计划，标题是**审阅计划**。**批准**接受计划。**继续规划**让 Agent 继续规划。

配对时没有**审批**权限时，这个停靠栏会显示**请在电脑上批准**和**这台手机配对时没有授予审批权限。** 请在电脑上完成批准。
