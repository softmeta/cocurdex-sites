Cocurdex 以**原生桌面应用**(Electron)形态交付。目标是给多 Agent 编程提供一个统一工作台——而不是包了一层浏览器壳的单条对话线程。

## 界面构成

工作台中常见的并列面板：

| 面板 | 作用 |
| --- | --- |
| **会话** | 跟踪并行的 Agent 运行，以及哪个需要你处理 |
| **对话** | 引导当前 Agent;只是若干面板之一 |
| **终端** | 集成 PTY,用于命令执行和 Agent 驱动的 shell 工作 |
| **编辑器** | 不离开应用即可查看和编辑项目文件 |
| **Git** | 查看差异、暂存并提交工作区变更；审查每个 Agent 回合改动的内容 |
| **浏览器预览** | 多标签预览你的开发服务器；设计模式下的标注可直接发到对话 |
| **PDF 阅读器** | 阅读文件树中的 PDF,支持目录、缩略图、搜索、书签和高亮 |
| **工作树** | 为会话提供隔离检出的托管 git 工作树（新会话勾选 **Worktree**;清单位于 **设置 → 工作树**） |
| **笔记 / Issue** | 应用私有的产品数据（见[笔记与 Issue](/zh-cn/docs/notes-and-issues/)） |
| **团队面板** | 当前主会话的队友、状态与回复（见[团队与编排](/zh-cn/docs/teams/)） |
| **脚本运行** | 等待批准的脚本提议与运行中的子 Agent（见[脚本编排](/zh-cn/docs/teams/#脚本编排)） |

右侧面板可以浮在对话之上，也可以点它的固定按钮停靠在旁边，让对话栏收窄而不是被遮住；选择会被记住。**关闭功能区**会把它藏起来。在 Windows 和 Linux 上，窗口在标题栏中使用跟随主题的原生窗口控件。

聊天布局在 **设置 → 常规 → 聊天布局** 中选择，下次启动会恢复：

| 布局 | 行为 |
| --- | --- |
| **中间栏** | 聊天作为主栏 |
| **浮动窗口** | 聊天浮在编辑器之上 |
| **右侧钉住** | 聊天钉在编辑器旁边 |

浮动或钉住布局下关闭聊天后，**关闭时隐藏聊天按钮** 会去掉右下角按钮；用聊天栏快捷键再打开。回复里生成的 HTML 可以在**聊天区**或**右侧浏览器**里预览。

预发布期间具体布局可能变化，但产品模型保持多面板：没有任何一个面板应该独占产品——对话是并列的一员，不是整个应用。

也可以在本机[用浏览器打开同一主机](/zh-cn/docs/devices-and-web/)，或配对另一台设备。

## 会话与注意力

你可以运行**多个**会话而不必合并对话记录。工作台会推导出一个**主状态**，让你一眼看出谁需要你：

| 类型 | 示例 | 该做什么 |
| --- | --- | --- |
| 需要你 | 待批准、等待输入、计划就绪 | 打开会话，处理权限、提问或计划 |
| 忙碌 | 工作中、连接中、监控中 | 等待；运行时支持的话可以引导 |
| 有结果 | 已完成 / 未读 | 查看产出，然后访问或继续以标记已了结 |
| 空闲 | 就绪 | 可以接受新任务 |

底层的会话状态值包括 `idle`、`running`、`error` 和 `exited`。UI 文案保持中性（「思考中」「使用工具」「等待后续输入」），不堆砌拟人化修辞。

### 会话列表

侧边栏的**会话分组与筛选**菜单控制会话如何列出：

| 控件 | 选项 |
| --- | --- |
| **分组** | 工作区、状态、Agent、最近更新，或不分组 |
| **排序** | 最近活动、创建时间或标题 |
| **筛选** | Agent、状态、环境（本地 vs Worktree）、来源、未读 |
| **每组显示会话数** | 限制根会话显示数量；**显示更多**展开其余 |
| **紧凑模式** | 更密的行 |

**置顶**把会话留在列表顶部。**归档**隐藏单个会话；分组上的**归档会话**会把符合的会话移到 **设置 → 已归档会话**，跳过已置顶、正在运行和等待中的会话——**撤销**可恢复。嵌套的子 Agent 会话可在树中展开和折叠。

### 执行树

会话侧边栏菜单里的**执行树**展示该会话的运行、工具调用、子 Agent 和待处理审批。展开一行查看内容；点选工具调用阅读输出。**只看问题**筛出失败的调用和等待审批的项。某些提供方原生的子 Agent 不可观察。

### 分叉与切换 Agent

侧边栏的**分叉会话**从当前会话开一个新会话。在用户消息上，**从这里分叉**会从该条提示开始分叉——方便另试一条路径而不丢掉原来的。新标题会带上「（分叉）」后缀。

会话未在运行时，可在输入框里换一个 Agent：Cocurdex 会把对话上下文交给新的运行时。Claude Agent 和 Codex 可以分叉到提供方自己的线程；记录里的标记可以**查看交接的上下文** / **收起交接的上下文**。Pi 侧边栏的 **Chat** 对话不能这样分叉或切换。

## 输入框

每个会话和每条后续消息都从输入框开始：

| 输入 | 作用 |
| --- | --- |
| `/` | 选择 skill 或 Agent 提供的 slash 命令 |
| `@` | 引用工作区文件作为上下文 |
| **+ → Skill / Issue / 笔记** | 插入 skill,或把 Issue、笔记作为标签附加；Agent 会在提示词里拿到完整内容 |
| 模型菜单 | Agent、provider、模型、推理强度、权限模式；**保存为角色**会把当前配置存为 [Agent 角色](/zh-cn/docs/agents/#agent-角色) |
| **Worktree** 复选框（新会话） | 在新建的[托管工作树](#工作树)中运行会话 |

轮次运行中发送的后续消息：Agent 支持引导时会注入当前轮次，否则排队到本轮结束（**设置 → 常规 → 后续消息行为**）。轮次结束后，它的工具调用会折叠到一个显示本轮耗时的标签后面；展开即可查看每一步。

**设置 → 常规 → 对话视图** 选择显示多少过程：**简洁**（只看最终回复）、**标准**（折叠摘要）或**详细**（全部展开）。

长记录里，提示导航条可跳到每条用户消息；**跳到最新消息**和**跳到顶部**可跳过滚动。回复上的上下文窗口计量会显示 token 用量；运行时压缩上下文时，记录里会记下这件事。

回复中指向文件的 Markdown 链接会在编辑器中打开，也支持 GitHub 风格的行号锚点，如 `src/app.ts#L32` 或 `#L10-L20`。回复里的 HTML 可以预览或查看源码；Mermaid 图提供**打开预览**和**下载 SVG**。

## 工作树

在新会话的输入框勾选 **Worktree**,发送时 Cocurdex 会创建隔离检出：分支名为 `cocurdex/<id>`,检出位于[工作树根目录](/zh-cn/docs/providers-and-settings/#工作树环境)下。也可以从选择器中挑一个已有工作树（勾选复选框时选择器不可用）。

- 工作区的 **setup 脚本**在后台运行，输入框不会被阻塞；首轮会等待 setup 完成，以免把它的改动算到 Agent 头上，进度显示为一行「准备 Worktree 环境」。停止只会放弃等待，不会杀掉脚本；setup 失败只报告一次，下一次发送会跳过它继续。
- 工作区的 **Actions**(例如「开发服务器」)出现在会话的 **…** 菜单中，每个都在新的终端标签中运行。
- 移除工作树时会运行 **cleanup 脚本**,并在应用创建的分支已合并时删除该分支。

## 审查变更

Agent 回合结束且改动过文件后，对话记录中会显示 **已编辑 N 个文件**卡片，并逐一标明文件是新增、修改、删除还是重命名。点击 **审查**可在 Git 面板中查看整个回合或单个文件。点击 **撤销**可将文件恢复到回合开始前的状态；如果文件在该回合之后又发生变化，撤销会被阻止；文件超过检查点大小或配额时无法撤销；回合仍在运行时也不能撤销。

在右侧面板的视图切换器中打开 **Git** 标签。**Diff 来源**菜单默认选择 **未提交**，还可选择 **已暂存**、**未暂存**、**已提交**（选择某次提交）、**分支**（比较源分支与目标分支）或 **回合**（会话回合捕获的快照）。回合快照可能过期。

只有在实时的 **未提交**、**已暂存**和 **未暂存**范围内，才能按文件或对全部文件执行暂存、取消暂存和丢弃；丢弃后无法撤销。面板支持分栏或统一 Diff、自动换行、显示完整文件、以树状或列表显示文件，以及筛选变更文件。如果工作区不在 Git 仓库中，面板会显示相应提示。

提交浮层提供 **提交**和 **提交并推送**。提交说明留空，或点击 **生成提交说明**，即可让 [设置 → Git](/zh-cn/docs/providers-and-settings/#git) 中选定的模型生成提交说明。

## 面板与窗口

- 会话面板的 **分屏**菜单提供 **向右分屏**、**向下分屏**、**关闭分屏**和 **关闭所有**。
- **在独立窗口中打开**会把对话移到单独窗口；点击 **移回主窗口**即可返回。分离对话前必须先打开编辑器面板。
- 终端支持多个标签页，可用 **新建终端**、**在终端中查找**和 **重启**。
- 可在编辑器的文件树中搜索文件。右键菜单提供 **添加到聊天**、**在访达中显示**（平台支持文件管理器时）、**复制路径**和 **复制相对路径**。
- 工作区里的 `.md` 文件可在标签栏切换 **预览** / **源码**。（应用私有的[笔记](/zh-cn/docs/notes-and-issues/)用笔记编辑器，不用这个开关。）
- 工作区包含多个文件夹时，可在 **编辑工作区**中管理 **源文件夹**，并使用 **添加文件夹**、**设为主文件夹**和 **移除文件夹**。将文件夹拖到窗口中即可将其作为工作区打开。

## 协作与写入模式

每个会话（在 Agent 支持时）：

| 控制项 | 含义 |
| --- | --- |
| **协作模式** | `default` 为正常工作；`plan` 为运行时支持的计划优先循环 |
| **写入模式** | `read-only` 与 `native-write`——Agent 是否可以通过其常规工具修改工作区 |
| **权限模式** | Agent 自动批准工具的激进程度（因 Agent 而异；见 [Agent](/zh-cn/docs/agents/)） |

优先选择仍能完成任务的最窄模式。

## 键盘快捷键

默认值在有助于肌肉记忆的地方与 VS Code / Cursor 接近。**Primary** 在 macOS 上是 ⌘,在 Windows/Linux 上是 Ctrl。可在 **设置 → 快捷键** 自定义。

| 操作 | 默认 |
| --- | --- |
| 文件 / 快速打开搜索 | `Primary+P` |
| 切换左侧边栏 | `Primary+B` |
| 切换右侧面板 | `Primary+\` |
| 切换编辑器全屏 | `Primary+Shift+E` |
| 切换对话坞 | `Primary+J` |
| 切换工作区搜索 | `Primary+Shift+F` |
| 切换浏览器设计模式 | `Primary+Shift+D` |

对话的发送键行为（Enter 还是 Primary+Enter 换行）可在设置中配置。

## 所有审批集中呈现

一切需要你处理的事项都出现在发起它的会话里：工具权限卡片、Agent 提问、计划审阅、脚本编排提议（可**查看脚本**、设置 Agent 上限、**运行**或**丢弃**），以及需要输入的队友。没有任何东西会在没有可见状态的情况下在后台运行。

## 主题

深色与浅色都是一等公民。除非你在设置中固定主题，否则建议跟随**系统外观**。主题对等是产品要求，不是事后补救。

## 浏览器设计模式

浏览器预览以标签页加载你的开发服务器（**新建标签页**打开空白页）。用上面的快捷键或浏览器工具栏打开**设计模式**,然后：

- 点击某个元素或拖出一块区域，创建带截图的标注。
- 添加评论，也可以附上想要的样式预览。
- 把所有标注作为一条格式化消息发到对话，Agent 能准确看到你指的是哪里。

标注浮层可以拖到一旁；**清除全部标注**会重置页面。

## PDF 阅读器

从文件树打开的 PDF 会在 PDF 阅读器中打开，而不是代码编辑器。它提供目录、页面缩略图、搜索、适合宽度 / 适合页面缩放、页面书签和四种颜色的高亮。书签和高亮由 daemon 保存。选中文字并选择**加入笔记**,即可把它摘录进[笔记](/zh-cn/docs/notes-and-issues/)。

## 桌面端掌管什么

本地产品数据（笔记、Issue、视图、标签、链接、搜索索引及相关状态）经由桌面 **daemon** 写入应用私有存储。公开网站和未来的团队控制台不会替代本机工作的这条路径。

见[工作区与数据](/zh-cn/docs/concepts/workspaces-and-data/)。
