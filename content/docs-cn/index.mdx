Cocurdex 是一个**桌面优先的多 Agent 开发工作台**。对话、集成终端、编辑器和浏览器预览共处一个外壳，让你同时运行多个 AI 编程 Agent，而不会搞丢哪个会话在等你。

## 心智模型

1. **是工作台，不是聊天窗口**——会话、对话、终端、编辑器和浏览器预览彼此平级，对话记录只是众多面板之一。
2. **并行会话**——同时运行多个 Agent，不把它们合并进同一段对话历史。
3. **如实的状态**——状态始终具体：思考中、使用工具中、等待你、有未读结果。
4. **Agent 协调 Agent，但由你掌控**——团队和脚本编排都是持久化的、由 daemon 托管，并受你的批准约束。
5. **本地优先的产品数据**——笔记、Issue 和演示文稿存放在本机的应用私有存储中。CLI 是受支持的外部边界；SQLite 文件不是公开 API。

## 你会得到什么

| 界面 | 作用 |
| --- | --- |
| **桌面应用** | 运行 Agent、编辑文件、预览 UI、管理笔记、Issue 与演示文稿的主要场所 |
| **Daemon** | 本地进程，掌管数据库、会话、团队、脚本编排、工作树和已安装的 ACP Agent |
| **CLI（`cocurdex`）** | 打开文件夹；管理笔记、Issue、演示文稿、搜索、Skills、Provider 与工作树；驱动会话和团队 |
| **产品 Skills** | 可选的 Agent skills（`cocurdex-*`），在应用私有数据上完成 PRD → Issue → 交付，以及演示文稿 |
